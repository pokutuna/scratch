Issue Artifact Probe

HTML、CSS、JavaScript のどの機能が GitHub Issue Artifact のパネルで動くかを 1 枚で確かめるページ。各カードの結果欄が緑の ✓ なら動作、赤の ✗ なら不動作。操作が必要なカードは「操作」に従う。カード下部の「Issue Artifact」は、このページを Issue に添付してパネルで開いたときの結果 (2026-11-17 に確認)。

  • 検証用 Issue: pokutuna/scratch#12 (artifact は GitHub にサインインしていないと見えない)
  • このページの artifact: Probe HTML / Markdown の artifact: Probe Markdown
  • 仕組みと制約のまとめ: README
  • 公式ドキュメント: Using artifacts with issues / Changelog
  • 参考記事:GitHub IssueにArtifactとしてHTMLとMarkdownを添付できるようになった
