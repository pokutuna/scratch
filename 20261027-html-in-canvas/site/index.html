HTML-in-Canvas Playground

<canvas> の子要素に置いた本物の HTML を、2D / WebGL のキャンバスに描き込むデモ集。 回転しても、歪んでも、3D 空間に浮かんでも、input には文字が打てるし、ボタンは押せる。

Chrome 156 以前でも、フラグを有効にすると試せます。

  1. アドレスバーに chrome://flags/#canvas-draw-element を貼り付けて開く
  2. ハイライトされた項目を Enabled にする
  3. 画面下の Relaunch で Chrome を再起動する

ページから chrome:// へはリンクできないので、コピーして貼り付けてください。 Chrome 156 で動くことを確かめています。それより古い Chrome では API が違い、一部のデモが動かないことがあります。

崩れた後も入力・クリックできる。部品の余白をつかむとドラッグできる
⚙️ 設定

2D コンテキストの drawElementImage() で、物理演算 (Matter.js) の剛体の位置と角度どおりに各要素を描く。 描くとヒットテスト用のジオメトリも自動で更新されるので、傾いたままの input やボタンをそのまま操作できる。

help と打ってみる
guest@canvas:~$

ターミナルは普通の HTML。WebGL の texElementSubImage2D() でテクスチャにして、 ブラウン管風のシェーダ (樽型歪み、走査線、色収差、ノイズ) を通して表示している。 キャレットの点滅も、入力した文字も、そのまま歪んだ画面に映る。

中央のメモを編集すると模様が変わる

同じ要素を drawElementImage() で何度も描ける。鏡像のコピーは { preserveElementGeometry: true } を付けてヒットテストに影響させず、 最後に中央へ描く 1 枚だけを操作対象にしている。
