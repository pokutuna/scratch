Kitesurf in Browser

Kitesurf ソースと README

Cloudflare Workers 上のブラウザエンジン Kitesurf から、Rust 製の中核だけを wasm のまま取り出して動かしています。 HTML と CSS を layout して canvas に描きます。Workers も Chrome も使いません。初回は wasm (gzip 後 約 8 MB) とフォントを読み込みます。

描画結果のリンクはクリックで開けます。ブラウザから取得するので、CORS を許可しているサイトだけ開けます (GitHub Pages や Wikipedia など)。Wikipedia の記事の URL は REST API の URL に置き換えます。

DOM コンソール

描画した DOM を DevTools のように調べます。$(sel) と $$(sel) が要素を返し、要素は text、innerText、html、attr(name)、style(prop) を持ちます。 Kitesurf の DomHandle の API を使い、コード自体はブラウザの JS で動きます。
