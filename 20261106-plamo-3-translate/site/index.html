PLaMo 3 Translate をブラウザで試す

Preferred Networks (PFN) が公開している翻訳特化 LLM「PLaMo 3 Translate」の GGUF を、 wllama (llama.cpp の WebAssembly 版、WebGPU 対応) でブラウザ内で動かす個人の試作です。PFN の公式のページではありません。

モデルは Hugging Face から直接ダウンロードし、ブラウザの OPFS に保存します (初回のみ 0.4〜1.8 GB)。

記事: 重み公開, PLaMo翻訳での提供開始 / モデル: 0.8B GGUF, 2B GGUF
